# ⚡ DevPulse

> A modern developer productivity dashboard built to track GitHub activity, coding goals, daily tasks, and repository insights in one place.

## 🚀 Features

- 🔍 Search GitHub users
- 👤 GitHub profile overview
- 📦 Repository statistics
- ⭐ Total stars tracking
- 🍴 Total forks tracking
- 💻 Programming language analytics
- 📊 Developer insights
- 🔎 Repository search
- 🎯 Coding goals
- ✅ Daily task management
- 📈 Task progress tracking
- 🌙 Dark/Light theme
- 📱 Responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub REST API
